# WordCraft for Arcun

This is the branch Arcun builds WordCraft's web editor from. It is based on
[WordCraft](https://github.com/storytold/wordcraft) by the ArtCraft team, licensed under the MIT License or the
Apache License, Version 2.0, at your option ([LICENSE-MIT](LICENSE-MIT), [LICENSE-APACHE](LICENSE-APACHE),
[NOTICE](NOTICE)).

It is a modified version, not an official WordCraft or ArtCraft build: it carries no ArtCraft name, wordmark or
logo and no links to the ArtCraft website or community, as the brand terms in
[docs/brand/LICENSE-brand.txt](docs/brand/LICENSE-brand.txt) require. [ARCUN.md](ARCUN.md) lists every change
and how the release is built. For WordCraft itself, its documentation and its community, see the upstream
repository.
